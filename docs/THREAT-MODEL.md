# Модель угроз

Дата: 15 августа 2026. Объект: демо-стенд интеллектуального ассистента автосервиса (`autoservice-demo.zernov.online`).

## Активы

| Актив | Почему важен |
|---|---|
| Учётные записи клиентов и сотрудников | Вход в кабинет, заявки, записи |
| ПДн (ФИО, телефон, email, госномер) | 152-ФЗ, репутация сервиса |
| Гостевые консультации и guest-токен | История симптомов без регистрации |
| Секреты (JWT, TOTP, SMTP, Redis, ключи интеграций) | Полный захват сессий и исходящих каналов |
| LLM/GPU/API-квота | Деньги и доступность публичного ИИ |
| Файлы (фото, PDF актов) | Подмена вложений, XSS через download |

## Акторы

- Аноним из интернета (демо публичное).
- Зарегистрированный клиент.
- Менеджер / администратор.
- Смежный контейнер в Docker-сети.
- Поставщик LLM (Ollama/OpenAI) как внешний обработчик.

## Границы доверия

Клиентский браузер → HTTPS edge → nginx VM → frontend/backend контейнеры → Postgres / Redis.  
Исходящие: SMTP, Telegram, OpenAI/Ollama, generic REST интеграций.

## Основные сценарии атаки и контроль

| ID | Сценарий | Контроль |
|---|---|---|
| T-01 | Подбор/перечисление аккаунтов через OTP | Одинаковый формат токена, маска ввода, dummy-ответ |
| T-02 | Кража сессии | httpOnly + `__Host-` cookie, CSRF double-submit, rotation + reuse detection refresh |
| T-03 | Обход 2FA | Backup-коды ≥80 bit, HMAC, staff setup-pending JWT (`stp`) |
| T-04 | DoS LLM | Лимит 8/2 на 15 мин, PoW гостя, квота сообщений сессии |
| T-05 | SSRF через интеграции | Блок private IP + DNS resolve + запрет absolute join |
| T-06 | Подмена вложений | Magic bytes, PDF как `attachment` |
| T-07 | Утечка ПДн в облачный LLM | `LLM_CLOUD_PII_ALLOWED=false`, redact перед OpenAI |
| T-08 | Доступ к Redis | `requirepass`, сеть только `app_net` |
| T-09 | Захват гостевой консультации | HMAC guest token, TTL 24 ч без заявки |
| T-10 | Неправомерная обработка ПДн | Журнал `consent_events`, export/delete API |

## Остаточный риск (демо)

- Staff 2FA на стенде временно выключен (`STAFF_2FA_REQUIRED=false`): менеджер/админ входят без обязательной настройки TOTP. На проде флаг по умолчанию `true`.
- Mailpit поднимается профилем `mail` только для демо-почты, не как интернет-SMTP.
- Это не замена пентеста и не аттестация УЗ.
