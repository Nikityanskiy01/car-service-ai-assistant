# Демо-сценарий (золотой путь)

**Длительность:** 7–10 минут live.  
**URL:** https://autoservice-demo.zernov.online или http://127.0.0.1:8080  
**Подготовка:** [ONBOARDING.md](./ONBOARDING.md).

## Перед прогоном

```bash
sudo docker compose --env-file .env.proxmox ps
curl -s http://127.0.0.1:3000/api/health
```

Ожидание: сервисы `healthy`, `{"status":"ok"}`. Если база пустая:

```bash
sudo docker compose --env-file .env.proxmox exec backend node prisma/seed.js
sudo docker compose --env-file .env.proxmox exec backend node prisma/seed.demo.js
```

## Учётные записи

Email: `client@example.local`, `manager@example.local`, `admin@example.local`.  
Пароли — из `DEMO_*_PASSWORD` в `.env.proxmox` (те же, что у `db:seed`).

## Сценарий

### 1. Гость — консультация и заявка (~3 мин)

1. Открыть `/consult` без входа.
2. Авто: **BMW X5**, год **2015**, пробег **140000**.
3. Симптомы: «биение руля при торможении»; условия: «при торможении».
4. Показать этапы в чате, блок «что поняли», причины и стоимость «от».
5. **Создать заявку (гость)** — имя и телефон `+7 900 000-00-01`.
6. Сообщение об успехе; при редиректе — вход с подсказкой claim.

**Резерв при сбое LLM:** rule-based ответ, сессия не обнуляется.

### 2. Клиент (~2 мин)

1. `/login` → `client@example.local`.
2. `/dashboard/client`: обзор, **Мои обращения**, **Записи**, **Гараж**.
3. Открыть обращение → переписка → сообщение.
4. При наличии отчёта консультации — просмотр / PDF.

### 3. Менеджер (~2 мин)

1. Войти `manager@example.local`.
2. Рабочий стол: «сделать сейчас», ближайшие записи.
3. Очередь → карточка заявки: сводка ИИ, диалог, телефон.
4. Сменить статус, ответить в переписке.
5. На сводке — быстрая оценка диагноза (верный / частично / нет).

**Telegram:** если бот не настроен, достаточно упомянуть, что событие пишется в `Notification`.

### 4. Администратор (~2–3 мин)

1. Войти `admin@example.local`.
2. Пульт `/dashboard/admin`: Status Strip, Action Inbox, KPI.
3. `Ctrl+K` → **ИИ → Сценарии** или **Аналитика**.
4. `/dashboard/admin/ai/status` — LLM, probe.
5. Операции → заявки: фильтры, bulk.
6. Аналитика — воронка.
7. Команда → пользователи — роль / блокировка.

## Типовые сбои

| Симптом | Действие |
|---------|----------|
| Сайт не открывается | `docker compose --env-file .env.proxmox ps` и логи frontend/backend |
| `LLM unavailable` | ключ и `LLM_CLOUD_BASE_URL` в `backend/.env`, карточка ИИ в админке |
| Пустые кабинеты | `seed.js` / `seed.demo.js` в контейнере backend |
| 401 | выйти, очистить cookies, войти снова |
| Старый UI | пересборка Compose, не Vite |
