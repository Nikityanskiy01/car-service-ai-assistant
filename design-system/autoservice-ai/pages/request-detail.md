# Request detail

> Overrides `design-system/autoservice-ai/MASTER.md` for the manager request dossier.

**Page:** Request detail (`/dashboard/manager/requests/:id`)  
**Mode:** Product UI workdesk, not a landing page  
**Dials:** Variance 5 / Motion 4 / Density 8

## Design read

Overhaul of an internal manager ticket desk for advisors who open requests all day. Dense Linear-tier garage console, matching workdesk / AI quality. Manrope + burnt orange. Display-type posters and empty black voids are defects.

## Rules

- Question from the client is a message card at body size, max 65ch. Never a hero headline.
- Missing car / booking / AI thread get composed empties with a next action, not a gray sentence in a void.
- Tabs: filled active plate, no orange focus ring leftover after click.
- Works is a 2-column bento. AI verdict + repair outcome live only here, never on Summary.
- History is a timeline rail; job errors sit on their own line with gap.
- Large type is reserved for the request number (~1.5rem) and ranked percents.
- Chrome controls share one row: status, assignee, assign-to-me. Call is a pill, never an underlined `tel:` link.
- Repair outcome is a 5-column field row with one-line labels; native selects/inputs use `.select` / `.input`.
- Client documents: one slot per type (work order, receipt, warranty, act, other), not a single type dropdown.
