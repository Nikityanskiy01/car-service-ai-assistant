# Home page overrides

> Overrides `MASTER.md` for the public landing.

## Pattern
Hero-centric car service site (not SaaS pitch):
1. Full-bleed hero — brand + one headline + one lead + CTA pair
2. Service rail (3 directions)
3. Chat diagnostic flow (4 steps)
4. Embedded chat demo panel
5. Trust strip
6. Final CTA

## Rules
- Brand name is hero-level (`hero-brand`), not only nav
- No cards in hero
- Primary CTA → `/consult` (AI diagnostic chat)
- Secondary CTA → `/booking`
- Soft UI Evolution surfaces below the fold; navy/blue tokens from Master
